# gyr · 北京最后一个秋冬 v2.2 — Real Map & Character Layer

本版新增：真实北京地图（OpenStreetMap + Leaflet）、地图点选真实坐标、按心情变化的小 gyr marker、朋友/狗狗 marker、动作字段、第一版 app icon + apple-touch-icon。

部署：将本目录全部文件覆盖上传到 preview 仓库根目录并 Commit。若 iPhone 主屏幕仍显示旧图标，删除旧主屏幕快捷方式后重新“添加到主屏幕”。

注意：地图瓦片与 Leaflet 首次加载需要联网；私人记录和照片仍保存在设备 IndexedDB 中。
